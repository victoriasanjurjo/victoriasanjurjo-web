¿Cómo empezar?

Empezar en programación es mucho más fácil de lo que parece y definitivamente no se trata únicamente de picar código como loco como muestran las películas. Este es un oficio hermoso lleno de desafíos y orientado a resolver problemas usando la lógica y el pensamiento crítico.

Lo primero que siempre recomiendo es descargar un entorno de desarrollo. El entorno de desarrollo será tu lugar para escribir código y programar lo que vos quieras. Para no tener que lidiar con suscripciones molestas ni configuraciones eternas, el entorno de desarrollo (o IDE) que utilizaremos en este sitio es Visual Studio Code de Microsoft.

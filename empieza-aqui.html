¿Cómo empezar?

Empezar en programación es mucho más fácil de lo que parece y definitivamente no se trata únicamente de picar código como loco como muestran las películas. Este es un oficio hermoso lleno de desafíos y orientado a resolver problemas usando la lógica y el pensamiento crítico.

Lo primero que siempre recomiendo es descargar un entorno de desarrollo. El entorno de desarrollo será tu lugar para escribir código y programar lo que vos quieras. Para no tener que lidiar con suscripciones molestas ni configuraciones eternas, el entorno de desarrollo (o IDE) que utilizaremos en este sitio es Visual Studio Code de Microsoft.

Para darles un poco de contexto, en Internet hay un debate desde hace años sobre cuál lenguaje de programación utilizar para empezar a programar. Este debate enfrenta dos lenguajes: Python y C. En este sitio, se utilizará el primero para explicar los fundamentos de la programación y encarar los primeros proyectos. Este enfoque se basa no solo en mi experiencia personal, sino también en el hecho de que Python es más amigable con los principiantes que quieren resultados tangibles rápidos y victorias claras sin tener que lidiar con la complejidad que acarrea empezar a programar con la terminal.

¿Qué es Python?

Python es un lenguaje de programación que se utiliza para múltiples objetivos en el mundo tecnológico. Pero en una primera instancia me enfocaré en explicar sus fundamentos y sus utilidades más básicas. Solamente para hacer un vistazo rápido a lo que se puede hacer con Python mencionaré brevemente que Python es utilizado tanto para análisis de datos como para desarrollo de software, o Machine Learning. Pero estos temas no se van a tocar por ahora.

Para empezar con Python no se necesita ser un experto en lógica matemática o tener conocimientos previos sobre programación. El único requisito previo es saber utilizar de manera básica la computadora y tener muchas ganas de aprender.
